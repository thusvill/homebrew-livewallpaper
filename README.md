# homebrew-livewallpaper

Homebrew tap untuk menginstal [LiveWallpaper](https://github.com/setiadijoe/LiveWallpaperMacOS) di macOS.

> **Catatan:** Ini adalah fork dari [`thusvill/homebrew-livewallpaper`](https://github.com/thusvill/homebrew-livewallpaper) dengan perbaikan untuk menghilangkan warning deprecasi Homebrew terbaru dan memperbaiki langkah `postflight_steps`.

## 📋 Prasyarat

- macOS Sonoma (14) atau lebih baru
- [Homebrew](https://brew.sh) sudah terpasang
- Homebrew versi terbaru (jalankan `brew update` terlebih dahulu)


## 🚀 Instalasi Cepat (Quick Install)

Copy seluruh perintah di bawah ini, lalu paste ke Terminal:

```bash
brew tap setiadijoe/livewallpaper https://github.com/setiadijoe/homebrew-livewallpaper && \
brew trust --cask setiadijoe/livewallpaper/livewallpaper && \
brew install --cask setiadijoe/livewallpaper/livewallpaper
```
